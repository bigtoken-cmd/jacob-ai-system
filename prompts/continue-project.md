# Continue This Project

Use the repository files as the source of truth for this task.

1. Read `PROJECT.md` and `STATE.md`.
2. Read only the current task section in `PLAN.md`.
3. Read the relevant domain pack.
4. Read only the source files and fixtures needed for the task.
5. Make the smallest safe change that advances the current task.
6. Run the required validation and tests.
7. Review the diff for unintended changes.
8. Update `STATE.md` with verified changes, failures, blockers, and one exact next action.
9. Record an important architectural decision in `DECISIONS.md` if one was made.

Do not treat attempted work as completed. Do not edit the live Obsidian vault. Do not connect accounts or perform external actions. Stop when a requirement is ambiguous or a test fails for an unresolved reason.
