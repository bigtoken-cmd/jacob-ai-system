# School Domain Pack

## Purpose

Organize assignments, explain material, support studying, and draft permitted work while respecting assignment-specific rules.

## Required behavior

- Verify the exact assignment and instructions.
- Follow source boundaries and AI/resource restrictions.
- Distinguish study help, draft help, staged answers, and final submission.
- Never treat an attempted answer as submitted or graded.
- Use simple wording when requested.

## Default output sections

1. Assignment identity
2. Rules checked
3. Answer or study explanation
4. Source support
5. Uncertainty or missing visual information
6. What Jacob must do next

## Acceptance tests

- The exact assignment rules were checked.
- No answer is presented as final when the assignment forbids AI assistance.
- Missing source information is labeled instead of guessed.
- Required prompt parts are all addressed.
